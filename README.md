# 萬年曆 · 抖音小程序

最小可用版本（單頁），包含農曆顯示、節日標記、月份切換，以及底部抖音 Banner 廣告位。

```
├─ app.js
├─ app.json

├─ project.config.json
├─ pages/
│  └─ index/
│     ├─ index.js
│     ├─ index.json
│     ├─ index.ttml
│     └─ index.ttss
└─ utils/
   └─ lunar.js
```

## 广告

广告位 ID：`a1lqvxb7vtr08rqdeu`

逻辑：**优先按「激励视频」**预加载并展示（与多数「一点就开」的小程序一致）；若该 ID 在后台实际是「插屏」，激励 `load` 会失败，代码会自动**再试插屏**。

- 已去掉「必须等 30 秒再点」的人为限制，进入即可点小贴士。
- 若两种都报「加载失败」，请到巨量后台确认该广告位类型与小程序类目、流量开关是否开通。

## 運行方式

1. 開啟「抖音開發者工具」。
2. 「匯入專案」→ 選擇 `G:\wannianli` 資料夾。
3. AppID 可填入您自己的小程序 AppID（測試可選「無 AppID 體驗」）。
4. 進入後即可預覽萬年曆與底部廣告位。

## 功能列表

- 即時顯示今天的公曆 / 農曆 / 干支 / 生肖 / 節日。
- 月曆視圖（6 週 42 格），標記今天、選中日、週末、節日、農曆初一。
- 工具列支援上/下月、上/下年，點擊「YYYY 年 MM 月」一鍵回到今天。
- 點任意日期可在頂部卡片切換顯示對應的農曆資訊。
- 點擊「小貼士」整塊區域即可彈出抖音插屏廣告。

## 備註

- 農曆演算法支援 1900–2100 年範圍。
- 樣式採用紅白主題，符合中國日曆風格。
